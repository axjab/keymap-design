# Silakka54 Keymap Design — Terminology Addendum

## Cluster Terminology

The term **cluster** is adopted as the primary term for a physically contiguous group of keyboard keys that is treated as a coherent functional unit.

This terminology follows the established convention of describing groups of related keyboard keys as clusters, including the terminology used by IBM keyboard designs.

### Definition

> **Cluster:** A physically contiguous group of keys treated as a coherent functional unit. Cluster membership is determined by physical grouping and/or intended function; keycap legends do not determine membership.

This distinction is important for the Silakka54 because available keycaps are being repurposed. A keycap may retain a familiar legend while its physical key performs an entirely different operation.

---

## Established Clusters

### Editing Cluster

The **Editing Cluster** is the three-key right thumb cluster dedicated to fundamental text-entry and text-editing operations:

    +----------+------+------+
    |   TAB    | DEL  | END  |
    |  1.75u   |  1u  |  1u  |
    +----------+------+------+
         |        |      |
         v        v      v
       SPACE  BACKSPACE ENTER

The keycap legends are donor artifacts:

| Keycap | Actual function |
|---|---|
| Tab | Space |
| Delete | Backspace |
| End | Enter / Return |

The Editing Cluster is governed primarily by:

- Topology Conservation
- Priority
- Grouping by Function
- Frequency
- Physical keycap constraints
- Semantic mnemonic quality

---

### Modifier Cluster

The **Modifier Cluster** is the three-key left thumb cluster reserved primarily for keyboard-behavior controls.

Candidate functions include:

- Ctrl
- Shift
- Alt
- Super
- Fn
- Other modifier/layer functionality as justified

The exact allocation remains TBD.

The intended conceptual division is:

    Modifier Cluster  -> keyboard/application behavior
    Editing Cluster   -> text manipulation

---

### Navigation Cluster

The **Navigation Cluster** refers to the conventional six-key navigation group used as the source of donor keycaps:

    Insert   Home   Page Up
    Delete   End    Page Down

This cluster is particularly relevant to the keycap-repurposing strategy.

Three of its keycaps have been selected for the Editing Cluster:

    Tab     -> Space
    Delete  -> Backspace
    End     -> Enter

The physical donor origin of a keycap and its current functional assignment are therefore treated as separate concepts.

## Terminological Principle

The documentation should distinguish between:

1. **Physical cluster** — where keys are located.
2. **Functional cluster** — what related operations they provide.
3. **Keycap identity** — the legend and physical dimensions of the donor keycap.
4. **Logical key identity** — the function generated by the firmware.

For example:

    Physical cluster:
        Editing Cluster

    Keycap:
        DELETE

    Logical function:
        BACKSPACE

These identities need not coincide.

This separation is fundamental to the present design because the Silakka54 keymap intentionally repurposes conventional keyboard keycaps while preserving useful physical and semantic relationships.
